# Goals, projects, and recorded work

Create a personal goal and choose **Link a task** to select a task from the last synced personal task collection. Create personal work in **My tasks**. The link stores the task ID, so renames and completions follow the original task. Recurring occurrences can be linked after the occurrence has been saved and synced. Deleted, skipped, and missing tasks leave a removable link and do not contribute to the percentage. Older linked workspace tasks remain available.

Select a project when creating a shared goal, or add it from the project's Overview. Shared goals can link tasks from that project. Each goal counts completed linked tasks out of its remaining linked tasks. If there are no countable tasks, it counts confirmed milestones out of all milestones. An empty or unavailable source has no percentage. Goal status is separate from calculated progress. Pausing, archiving, and restoring a goal keep its links. Shared project progress counts completed project tasks out of all current project tasks, excluding archived and cancelled work. The displayed time is when Planify calculated the result.

Project owners and admins manage assignments. Collaborators edit tasks they create or are assigned. Viewers can read authorized project data. The owner controls ownership and admin permissions. Invitation links are email-bound, expire, and are copied for sharing. Planify does not send invitation email. Retrying an accepted link cannot restore a removed membership.

A project task is available in your calendar if it is assigned to you, or you created it and it is unassigned. Open the task and choose **Plan in my calendar**, then review and approve the calendar proposal. The calendar label includes the task's short identifier. Calendar and focus records keep this label and the original ID in your personal workspace. Project descriptions, titles and member details stay on the project server. Reassignment or lost access hides the slot from your calendar. Your past focus time remains in your own time log. Task completion from focus is an explicit server-authorized write. Goal and project pages show your upcoming calendar slots and your saved focus time without copying those records or adding them to the percentage.

Personal tasks, calendar plans and focus still use Eya's account-scoped offline queue and conflict handling. The goal and project APIs require connectivity. Forms keep changes open on failure, and goal, project and project-task creation can retry with the same IDs. Goal and project detail edits send the version they were based on and report a conflict if the saved record changed. Shared planning and focus start recheck current assignment and membership online. Once started, a focus session can still be finished and recorded locally during an outage.

The workspace database adds the private goal-task link table and the paused status. Existing goal and project detail responses add counts and source information, and return a null percentage when no supporting data is available. There are new authenticated queries for synced personal task choices and eligible project tasks. The Eya snapshot format and the calendar and focus schemas are unchanged.
